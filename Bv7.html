👨‍👩‍👧 Mode Parent




    Un parent peut coller ici du vrai code Python.
    Python Aventure essaiera de le transformer en boîtes colorées.


























🧩 Comment ça marche ?




    1. Le parent écrit ou colle du vrai Python.





    2. L'application reconnaît les instructions compatibles.





    3. Elle crée les boîtes correspondantes.





    4. Les indentations Python deviennent la hiérarchie des boîtes.





    5. L'enfant peut ensuite modifier les boîtes.
