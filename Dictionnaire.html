Mode moteur

Le mode Agent est destiné aux objectifs nécessitant plusieurs recherches successives. Il conserve son état de mission séparément de la conversation affichée.

Mémoire

La mémoire conserve les conversations, concepts, relations, preuves, sources, recherches, stratégies, missions Agent, évaluations et statistiques.

Principe V8

Comprendre → planifier → chercher → observer les lacunes → enrichir → relier → vérifier → recommencer → synthétiser → mémoriser.
L'agent ne dispose pas d'une base de faits codée en dur. Il construit progressivement son état à partir des sources publiques disponibles.
